# SMS Spam Detection Using Machine Learning

## Objective
To classify SMS messages as Spam or Ham using Machine Learning.

## Dataset
SMS Spam Collection Dataset.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Algorithm
Multinomial Naive Bayes

## Feature Extraction
TF-IDF

## Steps
1. Load dataset
2. Explore data
3. Preprocess text
4. Convert text into TF-IDF features
5. Split into training and testing data
6. Train Naive Bayes classifier
7. Evaluate the model
8. Test new SMS messages

## Evaluation
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
